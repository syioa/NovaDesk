# NovaDesk
> It is basically an operating system running inside a web browser.

## Features
Currently NovaDesk has the following features -

- ⚡ Fast and light memory usage
- Notes app with markdown support
- Video Player with support for playing online videos. Thanks to [Plyr.js](https://plyr.io/)
- Weather app which supports many countries. Thanks to [Open-Metro](https://open-meteo.com/)
- Calculator app with support for scientific calculations
- Pomodoro Timer (Took inspiration from [Pomofocus](https://pomofocus.io/))
- Settings app
